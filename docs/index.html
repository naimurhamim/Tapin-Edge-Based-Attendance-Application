Key Design Decisions

90% Threshold

Students must attend
90% of classes to get
full marks. Approved
leaves count as present.
Geofence Security

Students can only scan
the teacher's QR code
if their GPS shows they
are inside the classroom.
Auto Lab Groups

The app reads the last
3 digits of the student
ID to automatically put
them in Lab G1 or G2.
Dual Attendance

Students can mark
attendance by tapping an
RFID card or scanning
the Teacher's QR code.
3-Sec Cooldown

The IoT scanner ignores
the same RFID card for
3 seconds to stop
accidental double taps.
Secure RFID Link

An Admin must manually
link a physical RFID
card to a student's
account before it works.
